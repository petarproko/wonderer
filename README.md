# Wanderer — Travel Agency Website

A modern, responsive travel agency website focused on discovering destinations and planning memorable trips.

## ✨ Features

- Destination hero section
- Tour packages with duration and price
- Customer testimonials
- "Plan Your Trip" CTA
- Responsive design for desktop, tablet, and mobile
- Informative footer

## 🛠️ Technologies

- HTML5
- CSS3
- Responsive CSS with Grid & Flexbox
